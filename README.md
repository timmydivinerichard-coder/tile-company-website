# Tile Company Website

An immersive tile, surfaces and interiors website concept built for **ABLE Integrated Homes & Interiors**.

The experience focuses on premium presentation and motion: a 3D tile hero, an interactive surface explorer, horizontal project storytelling, animated service states, and a cinematic call-to-action.

> Independent portfolio concept. This is not the official ABLE Integrated Homes & Interiors website.

## Features

- Interactive 3D floating-tile hero
- Surface explorer with animated detail views
- Horizontal scroll project showcase
- Hover-driven service imagery
- Smooth scrolling and motion transitions
- Responsive layout
- Netlify-ready configuration

## Tech

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- GSAP + ScrollTrigger
- Three.js / React Three Fiber / Drei
- React Lenis

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints in your terminal.

## Production build

```bash
npm run build
npm run preview
```

## Notes

The project uses remote Unsplash imagery for demonstration. No passwords, API keys, environment files, or other secrets are included in this repository.
